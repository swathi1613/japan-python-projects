# Japan-Focused Python Automation Projects

This repository contains Python automation scripts designed for processing Japanese text and handling currency conversions.

## 1. Japanese Morphological Text Analyzer
* Uses the `janome` NLP library to parse Japanese text and break down sentences into grammatical parts of speech.
* Automatically identifies and extracts unique Kanji characters from input text.

## 2. Live JPY Currency Converter & Logger
* Connects to live exchange rate APIs to convert Japanese Yen (JPY) to foreign currencies like USD.
* Automatically creates timestamped conversion history logs in a local text file.
